# java-lotto-precourse

### 입력 부분

- 입력값이 숫자 형식인지 확인(아니면 `IllegalArgumentException`) - 1, 2, 3번 공통 - **_1번 기능_**
- 입력값이 1부터 45사이 인지 확인(아니면 `IllegalArgumentException`) - 2, 3번 공통 - **_2번 기능_**
1. 구입금액
    - “구입금액을 입력해 주세요.” 프롬포트 출력 - `Console.readLine()` - **_3번 기능_** 
    - 입력값이 1,000원 단위인지 확인(아니면 `IllegalArgumentException`) - **_4번 기능_**
    - 입력값이 양수인지 확인 (0 이하는 `IllegalArgumentException`) - **_5번 기능_**
2. 당첨 번호
    - “당첨 번호를 입력해 주세요.”프롬포트 출력 - `Console.readLine()` - **_6번 기능_**
     - 쉼표 기준으로 분리 - **_7번 기능_**
    - 분리된 숫자가 정확히 6개인지 확인 (아니면 `IllegalArgumentException`) - **_8번 기능_** 
    - 6개의 숫자가 서로 중복되지 않는지 확인 (아니면 `IllegalArgumentException`) - **_9번 기능_** 
3. 보너스 번호
    - “보너스 번호를 입력해 주세요.” 프롬포트 출력 - **_10번 기능_**
    - 입력된 보너스 번호가 당첨 번호 6개와 중복되지 않는지 확인 (아니면 `IllegalArgumentException`) - **_11번 기능_**


### 출력 부분

1. 구매한 로또 정보 출력
    - 구입 금액에 따라 구매한 로또의 개수를 출력 - **_12번 기능_**
    - 구매한 각 로또의 번호(6개)를 오름차순으로 정렬하여 각 출력 - **_13번 기능_** 
2. 당첨 통계 출력
    - “당첨 통계”와 구분선(”`—-`”)을 출력 - **_14번 기능_**
    - 각 등수별(3개 일치 ~ 6개 일치) 당첨 개수를 계산 - **_15번 기능_**
    - 정해진 형식에 맞춰 각 등수별 당첨 개수를 출력 - **_16번 기능_**
3. 총 수익률 출력
    - 구매 금액 대비 총 당첨 금액의 수익률 계산 - **_17번 기능_**
    - 수익률은 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시 - **_18번 기능_**
    - “총 수익률은 62.5%입니다” 형식으로 출력 - **_19번 기능_**


### 로또 발행

- 입력받은 구입 금액을 1,000원으로 나누어 구매할 로또 개수를 계산 - **_20번 기능_**
- 구매 개수만큼 로또를 발행 → `Random.pickUniqueNumbersInRange(1, 45, 6)` - **_21번 기능_**
- 발행된 로또 번호들을 오름차순으로 정렬하여 저장 - **_22번 기능_**

### 당첨 여부 비교 및 등수 판정

- 각 로또마다 당첨 번호와 몇 개가 일치하는지 계산 - **_23번 기능_**
- 5개가 일치하는 경우, 보너스 번호와도 일치하는지 추가 확인 - **_24번 기능_** 
- 일치 개수 및 보너스 번호 일치 여부에 따라 각 로또의 등수를 판정 - **_25번 기능_**
- 당첨된 로또가 총 몇 개인지 집계 - **_26번 기능_**
- 당첨 통계를 바탕으로 총 당첨 금액 계산 - **_27번 기능_**
- 총 수익률 계산(소수점 둘째자리에서 반올림) - **_28번 기능_**

- 구입 금액, 당첨 번호, 보너스 번호 입력 과정에서 `IllegalArgumentException`이 발생하면, 에러 메시지를 출력(`[ERROR] ...`)하고 **해당 입력부터 다시** 받아야 합니다. (프로그램이 종료되지 않음)
